## **为什么要用免备案CDN？**

先把场景说清楚。

国内建站有个规矩：你的域名如果要通过80/443端口访问大陆服务器，必须有ICP备案号。没备案？对不起，请排队等审核。整个流程少则一个月，多则两三个月，而且还不保证一定过。

但如果你用的是**香港、美国、日本等境外节点**的CDN，就完全跳出了这个限制。境外CDN节点不在大陆监管范围内，域名不需要ICP备案就能正常接入。这就是免备案CDN的核心逻辑：**源站在哪里无所谓，CDN节点在境外，流量就从境外走**。

对于这几类人来说，免备案CDN基本上是刚需：

- 个人博客、测试站、短期项目，不想为备案耗时间
- 境外业务、跨境电商，面向海外用户，本来就不需要备案
- 服务器在香港/美国，想做内容加速但又不想被攻击打扁的站长
- 有国内访问需求但来不及备案的初创团队
